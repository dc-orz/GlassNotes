# 玻璃便签设计系统

桌面的主层级只有墨迹和玻璃。菜单保留 macOS 原生控件语义。视觉稿里的笔迹、玻璃和完成反馈分别有对应的运行时实现。

设计基线见[桌面全景](reference/glass-desktop.png)、[擦字分镜](reference/glass-erase.png)和 [v0.3 token 表](reference/glass-tokens-v0.3.pdf)。

| 设计职责 | 修改位置 | 使用约定 |
| --- | --- | --- |
| 语义值 | NoteDesign/Tokens.swift | 调整颜色、字号、留白、命中区、便签尺寸和动效时长时从这里改起 |
| 材质 | GlassSurface | 每张便签一层玻璃。组件统一处理系统版本与减少透明度 |
| 字体 | MarkerFont、InkContent、InkEditor | 正文与编辑器使用同一随包字体。第一行作为标题，其余保留换行，控制信息使用系统字体 |
| 操作 | SymbolAction | 图标控件自带统一命中区、辅助功能标签和悬浮提示 |
| 墨色选择 | Shared/InkPicker、InkPresentation | 创建与编辑共用同一选择器；存储值到视觉语义只映射一次 |
| 完成 | InkDismissal、InkWipe | 仅对文字施加擦除遮罩；玻璃层固定，最后整体淡出。恢复动作取消待执行的关闭 |

自动墨色跟随系统前景。静态墨色分别搭配明、暗材质，混合后的可读性以真实壁纸检查。原生玻璃的模糊与折射由系统控制。笔迹的粗细来自字体字形。示意稿的材质数值是视觉参考。

新增功能先查上表。标准系统按钮、菜单、选择器可以直接组合，专属的品牌外观和运动曲线归入 NoteDesign。评审时检查正文较长的卡片、亮暗背景、减少透明度、减少动态效果和键盘操作。
