# 原生桌面便签技术方案

## 系统与构建

目标为本机使用的 macOS 14+ 菜单栏应用。Swift Package Manager 构建应用与 CLI。AppKit 管理桌面窗口、状态栏、快捷键和弹出面板，SwiftUI 承载视图。仓库使用 macOS 26 或更新的 SDK 和 Swift 6.2+ 编译。应用运行时按系统版本选择玻璃实现。

## 从输入到窗口

菜单栏输入和原位编辑共用同一份便签状态。每张未完成便签拥有独立 NSPanel，位于桌面图标层上方、普通应用窗口下方。查看时，NotePanel 将右下角操作区以外的鼠标主键按下事件交给系统拖窗。当便签显示原生玻璃时，普通拖动先让它在桌面层获得焦点，松手后仍由系统焦点驱动折射。按住 ⌘ 拖动时保留当前窗口的键盘焦点。操作区使用按钮行的实际布局边界。滚轮和键盘事件走原生分发。右下角铅笔进入编辑态，正文支持定位光标和拖选文字，确认后保存，Esc 取消。窗口坐标按所在显示器可用区域的比例保存，以显示器 UUID 标识。显示器离线时临时映射到主屏，用户主动移动时再更新归属。

完成操作先记录完成时间。桌面视图收到新状态后擦去墨迹并淡出玻璃。撤销清除完成时间并恢复原位置。归档项保留正文和坐标。菜单栏面板提供恢复和永久删除入口。删除时按 ID 再次确认记录仍已完成，原子写盘后再关闭对应的桌面窗口和撤销浮条。

录制全局快捷键时，只在设置面板接收按键。注册使用 Carbon 的排他热键注册，新组合注册成功后再释放旧组合并保存。偏好兼容旧版预设，自定义组合保存物理键码和修饰键。

## 应用内更新

菜单栏的「检查更新」读取本仓库最新正式 Release，按版本和 Mac 架构匹配 DMG。用户点击「下载并安装」后，Shell 下载镜像，按 GitHub Release 资产的 SHA-256 摘要校验文件，并只读挂载。应用副本暂存在与当前安装位置相同的卷上，通过包标识、版本、架构、最低系统版本和代码签名检查后，用 `RENAME_SWAP` 原子替换当前应用。安装位置需要可写，旧进程在用户退出后结束，重新打开即运行新版。StatusMenu 持有更新状态，关闭面板后安装仍会继续，重新进入可查看结果或重试。

当前发布的包使用 ad hoc 签名，由本仓库的 HTTPS Release 元数据提供可信摘要，代码签名用于校验应用包内容。若已安装的副本使用证书签名，更新包还必须满足该副本的指定签名要求（designated requirement）。

## 持久化

首版本机单进程写入一份有版本号的 JSON 文档。选择它是因为数据只有便签和位置，容易备份，也能用临时目录验证故障恢复。文件只在用户操作时原子替换；写入成功后才改变内存快照。持有进程锁防止多实例写入。遇到损坏文件或更新版本时停止写入并告知用户。首次创建存档时放入四张可编辑示例，之后以存档为准。若增加 WidgetKit 或云同步，先重新设计跨进程写入与合并，再接入同一业务入口。

存档 v1 的 `createdAt` 和 `completedAt` 分别记录创建和完成时间。可选字段 `updatedAt` 随新建、正文编辑、完成和恢复写入。只移动便签或保存相同内容时保留原值。旧记录可以直接读取，缺失的修改时间保留为未知。

## 本地命令行

应用包在 `Contents/Helpers/glassnotes` 提供 CLI。CLI 通过 Launch Services 找到或后台启动对应的应用副本，连接用户临时目录下按进程 ID 命名的 Unix 域套接字。发送便签前，CLI 核对内核提供的对端 PID、审计令牌与应用签名要求。服务端只接受同一用户的连接。后台启动失败时，应用将原因写入该次启动的诊断文件，CLI 在标准错误中返回。NoteCommands 定义两端共用的请求和回复。Shell 在主队列处理命令，复用桌面窗口的选址、存储和状态通知。完成正在编辑的便签时，CLI 返回错误，以便用户先处理桌面草稿。等待回复超时后，CLI 提示查询列表再决定是否重试，以免重复创建。

应用启动时检查 `/usr/local/bin/glassnotes` 是否指向当前包的 CLI。设置面板复用这项检查，用户点击启用后才创建软链。遇到写权限不足时，macOS 提供管理员授权；同名文件和其他链接会保留。启动提醒的偏好保存在 UserDefaults。CLI 在后台拉起应用时，提醒延后到用户下次打开菜单栏面板。

## 设计系统

NoteDesign/Tokens.swift 为运行时样式的唯一来源。默认的桌面材质使用 NSVisualEffectView 的 behindWindow 混合并固定为 active，编辑、保存和失焦时共用同一块背景。macOS 26+ 的菜单栏面板与撤销提示使用系统 Liquid Glass，14–15 的界面使用 AppKit 毛玻璃。减少透明度时使用实色。桌面窗口和菜单通过 DesktopGlassPreference 订阅两项 AppStorage 偏好。macOS 26+ 的原生玻璃开关单独保存，默认关闭。开启后 desktopNoteGlass 使用系统的 clear 材质，窗口焦点驱动其外观，切换模式时沿用同一张便签和编辑内容。预设仍按原有字符串保存，自定义值在同一偏好键中一次写入基础预设、材质不透明度及压暗值。拖动滑块或恢复预设后，已打开的窗口就地刷新玻璃层，新建和恢复的窗口读取当前值。透明度独立于便签存档。存档 v1 中的 ink 字段仅作旧版读写兼容，原值在编辑时保留，新记录使用 chalk。桌面不采集屏幕内容。

标题和正文通过 SwiftUI 系统字体 API 渲染，按语言和字形覆盖回退。字体文件由 macOS 提供。标题使用中等字重，正文使用常规字重。完成时从左至右擦字 180 ms，再淡出玻璃 120 ms；减少动态效果时整张淡出 80 ms。撤销浮条保留 5 秒，之后仍可从已完成列表恢复。

参考 [Apple 自定义 Liquid Glass](https://developer.apple.com/documentation/swiftui/applying-liquid-glass-to-custom-views) 和 [Apple 应用字体指南](https://developer.apple.com/documentation/technologyoverviews/managing-the-fonts-for-your-app)。
