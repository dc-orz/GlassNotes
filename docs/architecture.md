# 原生桌面便签技术方案

## 系统与构建

目标为本机使用的 macOS 14+ 菜单栏应用。Swift Package Manager 构建三个 Swift 模块，AppKit 管理桌面窗口、状态栏、快捷键和弹出面板，SwiftUI 承载视图。仓库使用 macOS 26 或更新的 SDK 和 Swift 6.2+ 编译。应用运行时按系统版本选择玻璃实现。

## 从输入到窗口

菜单栏输入和原位编辑共用同一份便签状态。每张未完成便签拥有独立 NSPanel，位于桌面图标层上方、普通应用窗口下方。上沿是移动区域，点正文进入编辑，确认后保存，Esc 取消。窗口坐标按所在显示器可用区域的比例保存，以显示器 UUID 标识。显示器离线时临时映射到主屏，用户主动移动时再更新归属。

完成操作先记录完成时间。桌面视图收到新状态后擦去墨迹并淡出玻璃。撤销清除完成时间并恢复原位置。归档项保留正文、墨色和坐标。菜单栏面板提供独立于桌面动画的恢复入口。

## 持久化

首版本机单进程写入一份有版本号的 JSON 文档。选择它是因为数据只有便签和位置，容易备份，也能用临时目录验证故障恢复。文件只在用户操作时原子替换；写入成功后才改变内存快照。持有进程锁防止多实例写入。遇到损坏文件或更新版本时停止写入并告知用户。首次创建存档时放入四张可编辑示例，之后以存档为准。若增加 WidgetKit 或云同步，先重新设计跨进程写入与合并，再接入同一业务入口。

## 设计系统

NoteDesign/Tokens.swift 为运行时样式的唯一来源。模块内的玻璃组件在 macOS 26+ 调用系统 Liquid Glass，14–15 使用 NSVisualEffectView 的 behindWindow 混合。减少透明度时使用实色。由系统材质承担折射与磨砂，视觉稿中的模糊值是设计参考。默认墨色跟随系统前景，另有瓷白、炭黑和深青预设；预设配对明暗材质以维持字面可读性。桌面不采集屏幕内容。

字体随应用授权打包，正文和标题使用同一套中文马克笔字形。菜单、按钮和错误信息使用系统字体。完成时从左至右擦字 180 ms，再淡出玻璃 120 ms；减少动态效果时整张淡出 80 ms。撤销浮条保留 5 秒，之后仍可从已完成列表恢复。

参考 [Apple 自定义 Liquid Glass](https://developer.apple.com/documentation/swiftui/applying-liquid-glass-to-custom-views) 和 [霞鹜漫黑字体](https://github.com/lxgw/LxgwMarkerGothic)。字体源码版本为 1686033567898c451e08f8b6c0421975f27ac939，作者及授权文本随资源一起分发。
